# Razorpay Clone (Frontend Only)

This is a **frontend-only clone** of the Razorpay website, developed using **HTML, CSS, and JavaScript**. The project replicates the look and feel of the original Razorpay homepage and includes responsive design, animations, and interactive UI components.


---

## 🚀 Features

* ✅ Fully responsive layout
* 🎨 Modern and clean UI inspired by Razorpay's official website
* 💡 Hover effects and transitions
* 🧹 Modular, maintainable codebase using vanilla HTML/CSS/JS
* 📱 Mobile-friendly design
* 🖼️ Optimized images and assets

---



## 🛠️ Tech Stack

* HTML5
* CSS3 (Flexbox, Grid, Media Queries)
* JavaScript (Vanilla)

---

## 📦 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Abhi-2516/RazorPay_Clone
   ```

2. Navigate to the project folder:

   ```bash
   cd razorpay-clone
   ```

3. Open `index.html` in your browser:

   * Double click the `index.html` file
   * Or use Live Server in VS Code
